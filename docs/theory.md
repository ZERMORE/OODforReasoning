# 理论部分：定义、可验证命题与未验证假设

来源：[Liu et al. arXiv v4](https://arxiv.org/abs/2602.07253v4)，§2–4、附录 I–K。以下区分原文内容、代数结论及本项目研究设想。

## 1. 任务和边界

原文定义回答级检测；主实验用最终答案匹配作标签。token 索引不是语义推理步骤。错误答案、事实幻觉、推理错误、CoT 不忠实、严格 OOD 不可直接等同。

冻结 LLM，输入 x，生成 y1...yT。在预测 yt 前的状态，LM head 实际输入为 zt，线性输出 l= Wz+b，winner=argmax(l)。需要验证 head 确为线性且没有额外 logit soft-capping。本 runner 限定到经验证的 Llama/Qwen2。

## 2. NCI 与中心点

原文式 (2)：

$$s_{NCI}(z)=\cos(w_{\hat c},z-\mu)\|w_{\hat c}\|=\frac{w_{\hat c}^T(z-\mu)}{\|z-\mu\|}.$$

这是标量投影，不是纯 cosine；偏置不能直接加入该分子。

原文式 (4)、附录 J：最小化全词表 logit 方差，令 P=I-11ᵀ/V：

$$\hat z_* = -(W^TPW)^\dagger W^TPb.$$

代数结论：b=0 时最小范数解为 0；不必显式计算 P。非零偏置实现通过 WᵀW−(sum W)(sum W)ᵀ/V 与 Wᵀb−(sum W)(sum b)/V 分块求解。

**不能推出**：该点等于预训练特征真均值、语义中性点，或所有真实隐藏状态都能抵达它。最后归一化后的特征可能仅占几何空间的受限区域。零点作为 unconstrained 代理的有效性需要实验，而非由均值定义保证。

## 3. fDBD 与下界

原文式 (3)：

$$\tilde D(z,c)=\frac{l_{\hat c}-l_c}{\|w_{\hat c}-w_c\|}\le D(z,c),\quad c\ne\hat c.$$

因为 winner 是 raw-logit argmax，分子非负。该式到“候选超过 winner”的松弛半空间求距离，弱于要求候选超过全部类；逐候选通常不等于进入其完整决策区域所需距离。最近边界的特殊 tightness 不能推广为所有候选等式。

原文式 (6)、(7)：

$$s^k_{fDBD}(z_t)=\frac1k\sum_{c\in K_t}\frac{\tilde D(z_t,c)}{\|z_t-\mu\|},\qquad S=\frac1T\sum_t s_t.$$

K 为排除 winner 后 logit 最高的 k 个替代 token，不是包含 winner 的前 k 类。小 k 有效的假说是低概率远边界会稀释信号；这是经验性质，不意味着 k 越小越好。

## 4. 本项目可证明并测试的性质

- b=0、mu=0 时，z 乘任意正数，NCI 和归一化 fDBD 不变。
- 对所有权重行加同一向量 a：W'=W+1aᵀ，logits 仅增加相同偏移，softmax 与生成决策不变；同一 z 下、无偏置零中心的 fDBD 不变。
- 同一变换下 NCI 增加 aᵀz/||z||，一般不是对所有状态相同的常量，因此其排序可能变化。这是**本项目的代数分析**，不是作者已经实验证实的缺陷。
- 全词表 fDBD 与 k=V−1 数值等价；一并保留两种独立计算路径作交叉校验。
- 在线与同一 token 序列的 teacher forcing 应在浮点容差内一致；这只验证实现，不证明检测能力。

## 5. 待验证理论问题与实验

| 问题 | 假说/解释 | 对照与否证条件 |
|---|---|---|
| 几何归一化是否有额外信息 | 权重距离与特征范数能超越 margin/PPL | 同一生成比较 raw margin、norm-only、NCI、fDBD；配对 CI 无稳定增益则限制主张 |
| 序列平均能否追踪随机错误 | 后续状态可恢复不确定性信号 | 原文 Table 3 仅支持回答级 AUROC；另用步骤标签测首次错误后的延迟，不以均值 AUROC 代替 |
| 是否仅反映长度/格式 | 长度、抽取失败或高频标点解释部分差异 | 分长度、剔除抽取失败的敏感性分析、正确性相同的条件比较；报告各子集规模 |
| NCI 的参数表示敏感性 | 不改变模型概率的 common-row shift 仍可改变 NCI | 固定 z/轨迹作解析变换，验证概率不变再比较 NCI 排序；不重新训练或误称性能干预 |
| 能否做步骤级检测 | 几何信号可定位局部错误 | 需要独立步骤标签、step AUROC/AUPRC 与报警延迟，当前代码只保存 token trace，不实现此结论 |
| 是否能保证风险 | 校准阈值可在一定条件下控制错误 | 独立校准集、明确交换性等条件；当前 AUROC 不提供校准概率、置信保证或跨域统一阈值 |

这些研究必须在完成核心复现后单独运行并标记为扩展。未来与 ReProbe 比较时，统一目标模型、问题、生成轨迹、标签和成本；回答级与步骤级成绩分别报告。
