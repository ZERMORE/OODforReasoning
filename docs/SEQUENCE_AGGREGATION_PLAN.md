# OOD序列聚合与错误传播实验计划

状态：研究设计与工程执行计划。2026-10-26 已实现逐 token 回放、E1/E2 离线分析、E3 标注/位置分析和 E4 人工审核后的三分支续写入口，尚未运行服务器完整实验。执行说明见项目 `docs/SEQUENCE_STUDY_RUNBOOK.md`。本文细化既有 OOD 复现的研究扩展，不把预期结果写成实测结论。相关收集箱文件：[[OOD复现计划]]、[[OODeval1]]；保留原讨论稿，不直接覆盖。

## 1. 理论部分：修正论证与建立可证伪假设

### 1.1 可以成立的判断与需要撤回的断言

| 原表述 | 修订 |
|---|---|
| 算术平均本质上假设各步 i.i.d. | 不成立。对相关变量取均值在数学上完全合法；原评分也不因此成为独立概率模型。应讨论均值是否是适合任务的信息压缩。 |
| token 分类器互相独立 | 同一个 LM head 在不同、依赖历史的状态上重复使用，不是多个独立训练的分类器。 |
| 平均完全忽略自回归 | 过强。每步状态已由完整前缀决定；均值丢失显式顺序、局部分布与持续时长信息，但历史影响仍可能反映在分数值中。 |
| 违背马尔可夫性质 | 不宜使用。next-token 分布条件于完整前缀，并非默认一阶 token 马尔可夫过程；扩展状态下的马尔可夫描述也不禁止平均。 |
| 任何一步错，最终必错 | 不成立。模型可能自纠错；最终答案正确性与推理过程有效性必须分开标注。 |
| Min/分位数优于平均，直接证明顺序重要 | 不成立。这些是无序聚合，最多说明均值丢失了分布尾部信息。 |
| 早期错误一定比晚期难检测 | 未验证方向假设；错误持续、后缀长度、自纠错和评分位置效应均可能改变方向。应双侧检验并保留反向结果。 |
| 前缀错误必然导致所有后续状态异常 | 前缀干预可能改变状态，但变化未必大、未必持续，也未必投影到标量 NCI/fDBD 上。 |

更准确的研究命题：**在包含自回归历史信息的逐 token 几何分数上，全段均值可能不是回答正确性或过程错误的充分统计量；局部低分、顺序模式与错误后的置信度恢复可能提供额外检测信息。**

### 1.2 形式化与边界

对问题 $x$、回答 $y_{1:T}$，设 $h_t=f_\theta(x,y_{<t})$，token 评分 $s_t=g(h_t,W)$，分数统一为越大越可信。原聚合为：

$$S_{\mathrm{mean}}(y)=\frac1T\sum_{t=1}^T s_t.$$

对任意分数排列 $\pi$，$S_{\mathrm{mean}}(s)=S_{\mathrm{mean}}(s_\pi)$，说明它无法区分同一组分数的不同顺序。**这不是说改排文本后模型会得到同一组分数**，后者会改变上下文。

若 $m$ 个位置比参照置信度低 $\delta$，其余 $T-m$ 个位置与参照相同，则平均分下降为 $m\delta/T$。这是局部异常被长序列稀释的条件性示例；真实模型中后续状态会变化，不能据此推出所有早期错误必然被稀释。

PPL 的平均 log 概率满足 $\log P(y|x)=\sum_t\log P(y_t|x,y_{<t})$，不需要 token 独立；它有长度归一化联合概率的含义。NCI/fDBD 的均值没有由此自动获得“整条推理正确概率”的解释，也不把各步几何分数相乘来伪造该概率。

### 1.3 假设、主要比较与结论上限

| 假设 | 主要比较 | 可支持的结论上限 |
|---|---|---|
| H1 局部稀释 | 同一 token 评分的最低窗口 vs 全段平均；以 GSM8K fDBD-All 为主要比较 | 均值相较局部汇总损失可用信号；不等于时序或因果证据 |
| H2 顺序有增量信息 | 真实分数顺序的最低窗口 vs 打乱顺序的置换分布 | 实际排列有预测价值；还需排除阶段、长度与 token 类型混杂 |
| H3 错误传播且评分可能恢复 | 同题错误前缀 vs 原始/等价前缀的继续生成 | 指定干预及样本条件下的行为效应与评分失效；不等于自然错误的总体因果机制 |

早/中/晚错误的比较为机制诊断，不先规定早期必然更差。RNN/CNN 等监督聚合为可选扩展，不作为证明 H1–H3 的必要条件。

## 2. 工程部分：数据、评分与防泄漏协议

### 2.1 现有资产与缺口

- 已有 Qwen2.5-7B-Instruct 主实验，BF16、greedy、512-token 上限，模型 revision、prompt、样本 ID、原始 token ID 和标签在 manifest/predictions 中保存。
- 当前主实验共 CSQA 1,221、GSM8K 1,319、AQuA 254 题；这些是已经检查过的既有测试集，新聚合比较必须标为后续分析，不宣传为全新盲测。
- 主实验未保存逐 token 几何分数；已有 `ood_repro.deepconf` 仅回放 top-20 confidence 和 mean_logprob，**没有补齐逐 token NCI/fDBD**。不能直接用该文件运行本计划全部实验。
- 使用现有 `engine.replay(mode="matched")` 对原 prompt/response 做 teacher-forced replay，新增多评分 token 记录；不重新生成原自然轨迹，不改变已有标签。
- 确认后优先运行 GSM8K，再将冻结方案扩展到 CSQA/AQuA。Llama 权限获批后可作跨模型验证，不阻塞第一阶段。

### 2.2 数据分区

1. **工程 pilot**：从 GSM8K train 选 20 题，排除 few-shot 演示题和重复问题，只检查实现、标签规则及执行预算，不用于最终效应估计。
2. **独立 calibration**：另取 200 个 train 问题，记录 ID 清单，生成并评分，用于阈值、特征标准化及工程参数检查。pilot 与 calibration 不重叠。
3. **既有测试集后续分析**：保留 GSM8K 全部 1,319 题；CSQA/AQuA 做预先冻结协议的外部任务检查。不得按测试 AUROC 搜索窗口、阈值或 k。
4. **监督聚合扩展**：若实施，只在 train 建足够规模的多轨迹训练数据；按 question ID 划分训练/验证，任何同题种子、分支不跨集合。测试题完全不参与训练。200 个 calibration 问题不默认足够训练序列模型。

固定参数：主窗口 64，步长 1；32/128 仅作为预声明的敏感性分析，全部报告而不挑最好者。fDBD 保留既有 k 配置：GSM8K All，CSQA/AQuA 同时保留 All 与 100，不重新选择 k。

### 2.3 记录格式与一致性验收

每题额外记录：`source_predictions_sha256`、原 manifest 哈希、模型/tokenizer revision、软件包版本、回放模式、EOS 策略、样本 ID、token ID/位置、token 到文本跨度和步骤的映射、逐 token 分数及计分掩码。窗口/步骤聚合记录有效长度、窗口数及短轨迹退化情况。

核心 token 分数：`nci`、`fdbd_all`、已运行的 `fdbd_k100`、`logit_margin`、`mean_logprob`、`deepconf_top20`。EOS 策略与原实验一致，top-20 概率由全词表 log-softmax 获得。

把回放后的每个原评分重新平均，与原存储值比较；优先逐题检查全部指标，不只检查 mean_logprob。BF16 容差继承原 manifest 的 rtol/atol，报告最大误差及失败 ID，失败样本不得静默跳过。matched 回放减少前向形状差异，仍不能保证跨硬件逐位相同。

磁盘上每个完成样本立即写入独立输出，支持按 source/settings/environment 哈希续跑。原始结果只读。若中断导致最后一行不完整，报错并保留现场，不自动吞掉其他行。

### 2.4 标签与文本分段

保留 `final_correct`（最终答案）、`parse_failure`、`truncated`，新增 `process_valid`、`first_error_step`、错误文本跨度、错误类型、`recovered`、最终置信度恢复标签。最终正确的轨迹也可能包含后来被修复的过程错误，不能自动标为过程无错。

第一错误以“最早可独立判定的错误步骤/命题”为单位；token 起点仅作定位映射。跨多 token 的错误记录区间，不能声称单 token 标签天然精确。先用 20 个 train 样本冻结分段与标注规则；双人独立核验一部分样本，记录分歧与裁决，标注者不看评分曲线。

自然错误定位第一轮覆盖 GSM8K 的所有最终错误样本（当前结果 138 题），并随机盲审等量最终正确样本以发现自纠错。若需扩大过程错误检测评估，另报其抽样方案；该人工子集不直接代表全测试集的过程错误率。

## 3. E1：聚合方式交叉消融——先验证均值是否损失信号

所有方法使用同一轨迹与计分 token。对每一种 token 评分分别计算：

| 汇总 | 定义/约定 | 是否使用顺序 |
|---|---|---|
| Mean | 全段均值 | 否 |
| Min | 最低 token 分数；仅诊断，容易受噪声和长度影响 | 否 |
| Token bottom-10% | 最低 ceil(0.1T) 个 token 的均值 | 否 |
| Lowest window | 长度 w 完整窗口均值的最小值 | 是，使用局部邻接 |
| Window bottom-10% | 最低 ceil(0.1M) 个窗口均值的平均，M 为窗口数 | 是，使用局部邻接 |
| Step-equal mean | 每个推理步骤先平均，再对步骤等权平均 | 使用步骤边界，不区分步骤排列 |
| Head/Tail weighting | w_t=exp(±2t/max(T-1,1))，归一化权重后平均；正负两向均报告 | 是，使用绝对/相对位置 |

窗口长度不足 w 时使用一个覆盖全回答的窗口，并报告占比。不能把退化成 Mean 的结果当作局部机制证据。步骤划分排除纯格式行，但保留独立数学命题；无法可靠划分时不伪造步骤。

主要终点：GSM8K fDBD-All 的 Lowest-window(w=64) 相对 Mean 的回答错误 AUROC 差。其余评分×聚合为次要比较；另报 Window-bottom-10% 与 Token-bottom-10% 的差，以区分局部邻接和单纯尾部分布。

同时报告错误为正类的 AUPRC（注明错误率）、TPR@固定 calibration FPR、按长度分层结果，以及移除最终答案段后的诊断。移除答案段只改聚合掩码，不改前缀或重生成；不能用人工错误位置做部署可用的聚合。

## 4. E2：顺序置换——区分分布尾部与真正排列信息

对每题**同一组 token 分数向量**随机置换，多个评分通道使用同一排列；不打乱文本、不重新执行模型。对完整测试集构造 B=1,000 组置换，每组每题独立置换，再计算整组数据的 AUROC。

- 验收不变量：Mean、Min、Token-bottom-10% 在置换前后必须一致；多评分间同位置关系保持。
- 主要统计：原顺序 Lowest-window AUROC 与其 1,000 次置换分布比较。
- 双侧置换诊断 p 值：对原始值和 B 个置换值计算左右尾比例（均包含 +1 修正），取 2×较小尾比例，截断为 1；另报原始值减置换均值的效应大小。
- 置换检验的交换性假设未必对自然语言序列成立，因此这里视为“移除原排列的诊断”，不写成完全无假设的因果检验；问题级 bootstrap 另外估计效应不确定性，不能用 1,000 个置换当 1,000 个独立问题。

控制实验依次做：全轨迹置换；分开对前/中/后三段内部置换（保留粗位置）；以固定 16-token 连续块为单位重排（保留块内局部关系）；反转分数序列。

**反转控制的特别说明**：固定长度全部滑动窗口的均值集合在反转后不变，因此 Lowest-window/Window-bottom-10% 也应不变，不能用它们声称发现传播的方向。需要 Head/Tail 特征或监督有向序列模型检验方向性。

若真实窗口优于全置换，却不优于保留阶段的置换，优先解释为阶段位置差异。若所有置换都不影响预测能力，不能声称时序结构已得到支持，即使局部聚合优于均值。

## 5. E3：自然错误位置分析——相关性诊断

按第一错误 token 起点除以全回答 token 数得到相对位置，固定 [0,0.25)、[0.25,0.5)、[0.5,0.75)、[0.75,1] 四桶，另报绝对步骤索引和绝对 token 索引；没有过程错误/无法定位的样本另列。最终答案段内首次错误单独标识。

**错误样本单独一桶不能算 AUROC，因为缺少正确类。** 主要用 calibration 上冻结的全局阈值，报告每个最终错误位置桶的 TPR、漏检率和题数。最终正确轨迹中发生但被修复的过程错误单独分析，不混入最终错误 TPR。

若提供分桶 AUROC：每个错误桶与同一预先定义的正确样本池比较，并增加按回答长度、步骤数、截断状态匹配的正确对照；注明对照被多桶复用，差异用共享 question-ID bootstrap 计算，不能把桶当独立实验。

图表：置信度按首错位置对齐的均值/分位带、各位置桶 TPR、错误前后局部均值与全段均值对照、位置×长度二维表。窗口数越多越容易出现低值，需要长度分层；相对位置分母 T 自身受生成影响，因此此分析不作位置因果解释。

结果允许早期更差、晚期更差或无差异。不得只报告符合原设想的桶。若单桶错误少于 20，保留题数与宽区间，四桶结果仅作描述；不按显著性临时合并。

## 6. E4：反事实前缀干预——直接测传播与置信度恢复

### 6.1 样本与预算

先在另选的 30 个 train 问题的可验证正确轨迹上做干预流程 pilot，排除前述 200 个 calibration 问题；每题先用一个位置、三个分支、一个种子，共最多 90 次续写。正式阶段从既有 GSM8K 测试题中按冻结规则随机抽取 100 个“至少具有一个经核验正确中间计算步骤”的问题；固定 ID 与替换规则，达不到 100 时全部纳入并报告排除原因，不按效果挑选。

若进一步限制原始整条轨迹完全正确，必须人工核验并明确：结果只适用于原本正确、可编辑的轨迹，不能外推到全部自然错误。优先选两个不同相对位置的可编辑步骤，按位置最近原则匹配目标 25%/75%；不足两个则报告单位置样本。

正式预算上限：100 题×2 位置×3 分支×3 采样种子=1,800 次 continuation。温度 0.7、top-p=1、三个固定种子作为配对生成协议；另可用 greedy 做零随机性诊断，不重复 greedy 来伪装多个独立样本。每个分支最多继续生成 256 token，截断比例与正确率同时报告。

从前述 200 个 calibration 问题中另选最多 30 个可编辑问题，按相同规则做一个位置、三个分支、三个种子的续写校准，最多 270 次；这部分不参加正式效应检验。续写总预算上限因而为 pilot 90 + calibration 270 + 正式 1,800 = 2,160 次，另计自然回答及逐 token 回放成本。需要两个位置分别校准或扩大校准样本时，须在正式阶段开始前重新冻结预算。

这里采样多个 continuation 用于估计干预效应，不进行答案投票，不把它与单样本检测主实验混成同一指标。

### 6.2 三个分支

1. Original：保留原正确步骤，并在该步骤末尾截断。
2. Error：只修改一个关键计算结果/逻辑命题，使该步确定错误，尽量保持语法、token 长度和表达风格；在改后步骤末尾截断。
3. Sham：含义正确的等价表达编辑，在相同语义边界截断，控制编辑及措辞变化。

从三个截断前缀重新建立 KV cache，然后分别续写；不能沿用原正确分支的 cache。不能只把原固定后缀 teacher-force 一遍就称为传播实验。

数字可能由多个 token 表示，主干预以语义数值/命题为单位，不强求替换一个 token；记录重分词前后长度。替换多个字符仍可能是最小语义干预。逐题核验编辑确实改变了计算真值且没有引入无关含糊。

主要对照是 Error−Original 与 Error−Sham，Sham−Original 用于检查编辑混杂。所有分支的 prompt、生成参数、继续生成上限、seed 列表一致。相同 seed 只是配对协议，不保证分支分岔后采样噪声逐步完全相同。

### 6.3 三类量分别测，不用一个指标代替另一个

**行为传播（主要终点）**：题内多种子平均后的最终错误率差 Error−Original（并报告 Error−Sham），问题级配对 bootstrap CI。

**机制标签（人工/程序核验）**：是否在后续至少一个依赖该中间结果的步骤实际使用错误值；是否主动纠错；是否忽略注入内容；是否产生其他不相关错误。简单再次提及错误字符串不自动等于采纳错误前提。

**评分失效**：在确实采纳错误前提且最终错误的续写中，记录其通过 calibration 置信阈值的比例，并与原始均值、局部聚合对照。阈值只用相同续写协议的 train calibration 分支设置，不能直接把完整 512-token 自然回答阈值无校准迁移到 256-token 续写；至少同时报告原始连续分数，不依赖阈值定义唯一结论。

### 6.4 避免把人工注入的低分当作传播信号

分开保存：共同前缀分数、编辑步骤分数、**干预后新生成 token 分数**。主要机制分析仅用新生成部分；完整轨迹分数作为另一个诊断。

按干预后 token 距离比较 1–16、17–32、33–64、65–128，记录每个区间的有效题数和分支终止率；提前 EOS 不能当成后续高置信度，也不能只保留长续写而不报告选择偏差。

“置信度恢复”先报告 Error−Original 的连续差值曲线。需要二元恢复指标时，在 train pilot/calibration 冻结一个等效范围 epsilon（例如 calibration 的题内局部差值标准差的 0.2 倍，仅作为操作定义），只有后续区间差值 CI 完全落入 [−epsilon,+epsilon] 才称为与对照等效；“差异不显著”不等于恢复。Error 分支显著高于对照但仍错误时，另称为错误后的高置信度，不硬塞入等效恢复。

先发生局部低分、后来恢复/升高、且错误持续，才支持“局部异常被后续高分稀释”这一具体链条。如果从一开始就没有低分，更像 token 评分没有识别语义错误，不应归咎于平均聚合。

可选状态分析只存编辑后若干位置的 LM-head 输入范数、余弦差及相同后缀回放的表示变化，不保存所有层全部激活。自由续写中的状态差同时混合后续 token 差异，不能直接称为纯粹内部因果漂移。

## 7. 统计、监督扩展与结论规则

- 自然轨迹以问题为单位配对 bootstrap 2,000 次；干预时同题所有位置/分支/种子整组重采样。不能把 token、窗口或 continuation 当独立问题扩大样本量。
- 同时报告效应大小与 CI。H1/H2/H3 为三条预声明主要检验，需计算 p 值时预先指定双侧检验及 Holm 校正；不能把单独未校正的 95% CI 当作整套多重检验的 5% 错误控制。
- 主要 H1 为 fDBD-All/最低窗口/64/GSM8K；其他组合报告为次要或探索性。模型、数据集、窗口全部枚举，禁止只选最好结果。
- FPR 阈值使用 train calibration 的正确回答分数下 5% 分位数；报告 calibration 实际 FPR 及样本数。测试实际 FPR 未必恰好 5%，应照实报告。
- 小规模 pilot 只估计执行成本、可编辑比例、标签一致性与区间宽度；100 题不是功效保证。若 CI 太宽，结论为不确定；扩大样本的规则应在看正式效应前冻结，避免按显著性停机。
- 有监督 RNN/CNN/attention 需与同数据训练的无序模型比较：均值+方差+分位数+长度的 logistic regression，以及容量尽量匹配的无位置集合聚合器。加入打乱训练/测试、位置编码移除和方向反转消融。只赢无监督 Mean，不能证明顺序有价值，也不能继续声称 training-free。
- 检测指标与最终答题正确率、过程错误定位指标分开报告；AUPRC 只在明确抽样分布下解释，人工平衡样本上的 AUPRC 不代表原测试错误率下的表现。

## 9. 哪些结果会推翻或收窄原假设

1. 各聚合无稳定差异：当前数据不支持均值是主要瓶颈。
2. 分位数有效，窗口/顺序没有额外收益：支持分布尾部信息，而不支持时序解释。
3. 错误注入常被修复且正确率不降：不能说存在普遍不可逆级联。
4. 错误发生后所有分数都持续偏低：不符合“后续虚假自信稀释”的具体机制，可能是聚合/阈值或长度问题。
5. 从注入处起评分始终高、局部评分也无效：主要是语义错误与 token 几何置信不一致，不只是均值问题。
6. 只在人工编辑上有差异，自然错误没有：可能存在编辑分布偏移，需要限制外推。
7. 监督序列模型只赢 Mean、不赢无序监督对照：不能归因为依赖建模。

可支持的谨慎结论示例：“在固定模型和任务下，均值相较某些局部汇总损失了错误检测信号；前缀干预进一步表明，部分错误可在高置信度续写中持续。该证据支持针对聚合及条件性置信度的改进，不构成对 token 分类视角本身的否定。”
